Bienvenue ! Cette note liste ce qu'il te faut la première semaine.

- Messagerie : le canal #produit pour les échanges du quotidien, #incidents pour les alertes.
- Code : le dépôt NoteFlow sur la forge interne. Demande l'accès à Bruno.
- Suivi : le tableau des tâches dans NoteFlow lui-même, projet Produit.
- Documentation : les spécifications et les décisions sont des notes, rangées par projet.

L'accès à la base de données de production n'est pas donné à l'arrivée : il suit le process de gestion des accès, géré par Chloé.
