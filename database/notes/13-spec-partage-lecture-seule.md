Un utilisateur peut générer un lien qui permet de lire une note sans compte NoteFlow.

Règles :
- le lien est long et non devinable, et peut être révoqué à tout moment ;
- la page partagée n'affiche que la note, sans les autres notes du projet ni les commentaires ;
- aucune image externe n'est chargée dans la page partagée ;
- chaque ouverture du lien est journalisée.

Maquettes : version 2 du 16/09/2026, validée par Alice. La révocation a été ajoutée après le point avec le client pilote.
